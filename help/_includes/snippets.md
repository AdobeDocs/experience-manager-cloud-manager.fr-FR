# Extraits (#snippets)

## Problèmes connus de copie de contenu {#content-copy-known-issues}

Lors de l’utilisation de la fonctionnalité [copie de contenu](/help/using/content-copy.md), si une ressource de l’environnement source est renommée, l’opération de copie de contenu peut échouer en raison de conflits d’UUID dans l’environnement cible.

Pour éviter cette erreur, au lieu de renommer les ressources, supprimez-les d’abord, puis recréez avec le nouveau nom de ressource souhaité.
