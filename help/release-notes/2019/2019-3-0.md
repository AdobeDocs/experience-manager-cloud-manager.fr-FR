# Notes de mise à jour de la version 2019.3.0 de Cloud Manager {#release-notes-for}

La version  2019.3.0 ajoute la création de rapports SLA à la fonctionnalité de surveillance du système fournie dans la dernière version.

## Date de publication {#release-date}

La date de publication de la version 2019.3.0 de [!UICONTROL Cloud Manager] est le vendredi 21 mars 2019.

## Nouveautés {#whats-new}

* Les rapports de contrat SLA sont désormais visibles dans Cloud Manager. Consultez [&#x200B; Surveillance de vos environnements &#x200B;](/help/using/monitoring-environments.md) pour plus d’informations.
* Les pages d’aperçu et d’exécution du pipeline ont été restructurées pour mieux tirer parti de l’espace vertical.
* La page Activité utilise désormais un format de date long.

## Correctifs {#bug-fixes}

* Certains graphiques de surveillance n’étaient pas affichés de manière cohérente.
* Si la surveillance était mal configurée, le message d’erreur apparaissait plus fréquemment que prévu.
